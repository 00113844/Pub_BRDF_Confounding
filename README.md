# Pub_BRDF_Confounding

Code and data for **"Same canopy, different place: sun-view geometry biases vegetation-index LAI
retrieval of ryegrass and wheat across Australia, and a sun-aware multi-angle index combination
reduces it"** (manuscript in preparation for *Computers and Electronics in Agriculture*).

Author: Gustavo Togeiro de Alckmin, The University of Western Australia
([ORCID 0000-0002-0665-9426](https://orcid.org/0000-0002-0665-9426)).

Identical perennial ryegrass and wheat canopies are simulated with PROSAIL (PROSPECT-5B + 4SAIL)
at 19 Australian sites and on a 0.5° continental grid, under handheld, Sentinel-2 and UAV
sun-view geometries. The pipeline quantifies how geometry alone changes vegetation indices and the
LAI / canopy chlorophyll derived from them, and tests multi-angle retrieval as a remedy.

## Contents

| Path | What it is |
|---|---|
| `src/publication_spectral_data/` | PROSAIL engine wrapper, solar geometry, geometry scenarios, look-up tables, indices, trait models, multi-angle inversion |
| `scripts/run_australia_scenarios.py` | Experiments E1–E5: `python scripts/run_australia_scenarios.py [e1 e2 e3 e5]` |
| `scripts/crosscheck_prosail.py`, `.R` | Verification against the Python `prosail` and R `prosail` packages |
| `vendor/pyprosail/` | Patched PyProSAIL (LGPL-3.0-or-later); every change is listed in `PATCHES.md` |
| `data/crop_parameters/`, `data/sites/` | Sourced wheat growth-stage parameters (each value linked to a publication) and the 19 sites |
| `docs/drafts/prosail_params/` | Parameter sourcing notes for *Lolium* and *Triticum* |
| `docs/drafts/scripts/`, `docs/drafts/figures/` | Figure scripts (incl. the scene schematic) and manuscript figures |
| `results/logs/`, `results/figures/` | Result tables and figures |
| `app/` | Streamlit explorer for planning acquisitions |
| `tests/` | `pytest` suite |
| `docs/wiki/` | Engine, geometry conventions and troubleshooting notes |

Conventions: `raa = 0` is the hotspot (sensor on the sun's side), wrapped to [0, 180];
spectra are indexed by `wavelength - 400`; `rsot` (BRF, direct sun) is the primary reflectance
factor and `resv` (sun + sky) the secondary one; the reference geometry is nadir, SZA 45°.

## Running

Python 3.12. The PROSAIL Fortran extension needs a Fortran compiler (on Windows, MSYS2 UCRT64
gfortran; see `vendor/pyprosail/README.md`).

```bash
uv sync                 # or: pip install -e . ./vendor/pyprosail
pytest -q
python scripts/run_australia_scenarios.py e1 e2 e3 e5
```

Processes, not threads: the Fortran engine keeps module state.

## Status

This repository is being assembled for archiving on Zenodo. Not yet included: the terrain (E6),
index × view-angle selection (E8) and 50-canopy multi-angle robustness code and outputs, and the
facts table behind the numbers in the manuscript.

Two large result tables are stored gzip-compressed (`results/logs/aus_trait_errors_sites.csv.gz`,
`results/logs/aus_vi_uav_sites.csv.gz`; 106 and 156 MB uncompressed). `pandas.read_csv` reads them
directly; both are regenerated by `run_australia_scenarios.py`.
